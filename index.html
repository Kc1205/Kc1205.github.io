Hospital Management System

A sophomore-year project built with two classmates: a hospital system that applied data structures and algorithms from my Advanced Data Structures class — HashMaps, quicksort, and BST-based maps — to power a patient registry, a triage queue, and treatment logs, with CSV import/export and performance benchmarking across sample workloads to compare data structure choices. My first project written in Java.

Java HashMap Quicksort BST Triage queue CSV I/O

Another sophomore-year Java project: a system for scheduling and managing room reservations across a university, modeling entities like students, faculty, courses, rooms, and events.
